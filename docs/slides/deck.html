Testing the tests

The hidden tests catch the bugs that the trace misses

Every reference passes (62 of 62). Every deliberate bug fails the hidden tests (222 of 222 bug runs). Checked against the visible trace alone, 29 of those bugs would have passed.

Bug runs caught, by family
Bugs include a wrong reset, wrapping one early, a wrong transition, reversed priority, and dropped or duplicated words. Each runs on every task of its family.
